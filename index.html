🔈 Máy của bé chưa có giọng đọc Tiếng Việt. Lời đọc có thể chưa chuẩn.
Cách cài đặt
  • macOS / iPhone / iPad: Cài đặt → Trợ năng → Nội dung được đọc → Giọng nói → thêm “Tiếng Việt (Linh)”.
  • Windows: Settings → Time & Language → Language → thêm “Tiếng Việt” (có Speech).
  • Android: Cài đặt → Chuyển văn bản thành giọng nói → Google → tải dữ liệu Tiếng Việt.
  • Hoặc dùng trình duyệt Microsoft Edge (có sẵn giọng Tiếng Việt trực tuyến).
